MB once int add (Админ) — что это и как работать

По-русски:
Страница показывает список этрапов, для которых через "once int add" были добавлены записи YhlasIyul2026InternetNach (кто, когда, сколько строк, сумма), позволяет скачать все строки этрапа в Excel и полностью откатить (удалить) добавление — вернуть к состоянию "как будто не добавляли". Доступ только у admin1.

Когда откат НЕ сработает: если этрап уже НАЧИСЛЕН в NachMinus (is_nach = True хотя бы у одной строки), кнопка "Откат" будет заблокирована и заменена на "Откат запрещён" — сначала нужно откатить начисление, и только после этого этрап можно будет откатить здесь.

Пароль: при нажатии "Откат" появляется поле для пароля — без верного пароля ничего не удалится (покажет ошибку). Это дополнительная защита от случайного нажатия.

После успешного отката этрап снова можно будет загрузить заново через страницу "once int add" (там стоит проверка "этрап уже добавлен один раз").
