MB once int nach - откат начисления

Откатывает начисление, сделанное на странице "once int nach": возвращает балансы абонентов и соответствующее поле NachMinus (internet/alem/belet) назад. После отката этрап+услуга снова станет "не начислен", и её можно будет либо начислить заново, либо откатить полностью (удалить) на странице "MB once int add".

MB once int nach (Админ) — что это и как работать

По-русски:
Страница для отката начисления, сделанного через "once int nach". В списке — только уже начисленные (is_nach=True) этрапы. Доступ только у admin1.

Что происходит при откате:

  • Для каждой строки YhlasIyul2026InternetNach этрапа находится абонент (UserTable по number+etrap) и сумма (Аренда) суммируется по абоненту.
  • Соответствующий баланс UserTable (b_internet для Internet/Belet, b_alem для Alem) увеличивается обратно на эту сумму, поле NachMinus (internet/alem/belet, за 2026-07) уменьшается на эту же сумму — ровно на то, что было начислено, ничего больше. Сама запись NachMinus не удаляется (там могут быть другие начисления того же периода).
  • `YhlasIyul2026InternetNach.is_nach` возвращается в False (и `who_nach`/`nach_at` очищаются) — после этого можно либо начислить этрап заново на странице "once int nach", либо полностью откатить (удалить) add на странице "MB once int add".
  • Если для какого-то абонента не находится UserTable или NachMinus за 2026-07 — откат полностью прерывается (ничего не меняется), чтобы не оставить частично откаченные данные.

Пароль: при нажатии "Откат начисления" появляется поле пароля — без верного пароля ничего не изменится.
